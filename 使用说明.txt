CornerBreak · 角落小憩  v0.1.0

给忙碌的工作留一点休息时间。

一、运行环境与启动

需要 Windows 和 .NET Framework 4.7.2 或兼容更新版本。
完整解压后，双击 CornerBreak.exe 启动，运行时保留托盘图标。
这是 C# 桌面程序，运行时无需 PowerShell 或 VBScript，也无需管理员权限。
请保留 CornerBreak.exe.config。三张角色图片已经内嵌在 EXE 中，运行时无需 assets 文件夹。
重复启动不会运行第二个提醒程序，而会打开已有的状态窗口。
退出程序请右击托盘图标，选择“退出 CornerBreak”。

二、休息提醒

每小时的 50 分至下一个整点是休息时段。例如 14:50—15:00。
卡片集中显示三项提醒：眼睛休息、喝点水、起身活动。
每项都可在设置中单独开关，共用同一个休息时段。
中途启动或打开卡片时，会显示本轮实际剩余时间。

默认开启“随倒计时逐渐放大”：50 分开始保持常态，随后卡片和文字逐渐变大，越接近整点越明显。
卡片固定右下角，向左上方扩展；上限约为当前屏幕工作区宽度的一半、高度的 80%，并始终受屏幕边界限制。
鼠标停在卡片上、拖动窗口、打开菜单或设置时暂停放大；结束操作后平滑继续。
暂停、本轮跳过或提醒结束后恢复常态，下一轮从正常大小开始。
可在“提醒设置”中取消“随倒计时逐渐放大”，保留固定尺寸提醒。

点击“本轮不再提示”，本轮休息时段内不再自动弹出提醒。
关闭窗口的 × 同样会收起卡片，并跳过本轮提醒。
跳过状态在重启后仍然有效，到本轮结束时自动失效。
从托盘查看状态不会取消本轮跳过。

三、暂停和恢复

可暂停 30 分钟、1 小时或 2 小时，也可选择暂停至手动恢复。
暂停期间不自动弹出提醒，可从托盘查看状态或恢复提醒。
暂停状态会在重启后保留；限时暂停到期后自动恢复正常时段规则。

四、选择休息伙伴

内置“猫猫探头”“蓝色大肥鱼”“二次元伙伴”三种角色，默认使用猫猫探头。
右击托盘图标，在“休息伙伴”子菜单中选择，卡片立即切换并记住选择。
也可打开“提醒设置”，在“休息伙伴”下拉框中查看预览，点击“保存”后生效；取消不会修改原设置。
选择“不显示角色”可使用简洁文字卡片，角色区域会自动收起。
角色随卡片一起放大，不改变提醒时间、倒计时或暂停规则。

五、设置、搬迁和升级

提醒开关、角色选择、渐进放大、暂停和本轮跳过状态会自动保存在 EXE 同目录的 Data\settings.json。
请将程序解压到有写入权限的文件夹。
需要搬迁工具时，保留 CornerBreak.exe、CornerBreak.exe.config 和 Data 文件夹。
从旧脚本版升级时，把新程序及配置文件放在原目录，保留原有 Data\settings.json。
程序不联网，也不会自动设置开机启动。
发布 ZIP 不包含任何用户的 Data 文件夹，首次保存设置时会自动创建。

六、开发构建和预览

以下命令用于源码目录；普通用户直接双击 EXE 即可。
构建阶段使用 Windows PowerShell 5.1，日常运行不需要脚本启动器。

  .\Build.ps1 -Test

编译程序、执行 C# 自检，生成 dist\CornerBreak.exe。

  .\Package.ps1

构建、测试并生成 release\CornerBreak-v0.1.0-windows.zip 和 SHA256 校验文件。

  .\dist\CornerBreak.exe --preview

打开提醒卡片预览，不写入真实设置。预览结束后关闭窗口即可。

  .\dist\CornerBreak.exe --preview --previewmascot fish

预览蓝色大肥鱼。角色参数还可使用 cat、companion、none。
