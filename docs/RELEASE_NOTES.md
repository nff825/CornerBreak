# CornerBreak v0.1.0：角落小憩

Windows 桌面休息提醒工具，在屏幕角落提醒眼睛休息、喝水和起身活动。

## 功能

- 三项提醒可以分别开关，共用每小时 50 分到整点的休息时段。
- 休息时段内，卡片、文字和伙伴逐渐变大；有尺寸上限，也可以关闭。
- 猫猫探头、蓝色大肥鱼、二次元伙伴可供切换，也可隐藏角色。
- 支持暂停 30 分钟、1 小时、2 小时或至手动恢复，以及跳过本轮提醒。
- 无需账号、不联网，设置保存在本机。
- 原生 C# EXE，三张角色图片已嵌入程序，运行时无需 PowerShell 或 VBScript。
- README 提供六张项目介绍图与程序真实界面截图。

## 下载与运行

下载 CornerBreak-v0.1.0-windows.zip，完整解压后进入 CornerBreak 文件夹，双击 CornerBreak.exe。

需要 Windows 和 .NET Framework 4.7.2 或兼容更新版本。请保留 CornerBreak.exe.config。

CornerBreak-v0.1.0-windows.zip.sha256 用于核对 ZIP 的 SHA256。

## 保留个人设置

设置位于程序同目录的 Data/settings.json。搬迁或升级时保留 Data 文件夹。
