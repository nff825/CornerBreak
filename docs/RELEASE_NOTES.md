# CornerBreak v0.2.0：常驻小挂件

Windows 桌面休息提醒工具。新增默认开启的常驻小挂件，平时也能看到伙伴和下一次休息倒计时。

## 功能

- 平时显示小挂件，到每小时 50 分自动展开提醒；整点、暂停或跳过后回到小挂件并显示当前状态。
- 点击挂件打开详情，拖动后记住位置，右击使用共享菜单；自动显示不抢输入焦点。
- 从提醒设置或托盘“常驻小挂件”切回定时弹出模式。
- 详情窗口 × 和“收起详情”只收起，不再代表跳过；“本轮不再提示”明确记录本轮跳过。
- 三项提醒可以分别开关，共用每小时 50 分到整点的休息时段。
- 休息时段内，卡片、文字和伙伴逐渐变大；有尺寸上限，也可以关闭。
- 猫猫探头、蓝色大肥鱼、二次元伙伴可供切换，也可隐藏角色。
- 支持暂停 30 分钟、1 小时、2 小时或至手动恢复，以及跳过本轮提醒。
- 无需账号、不联网，设置保存在本机。
- 原生 C# EXE，三张角色图片已嵌入程序，运行时无需 PowerShell 或 VBScript。
- README 保留六张 v0.1.0 项目介绍图，新增常驻小挂件和设置的真实截图。

## 下载与运行

下载 CornerBreak-v0.2.0-windows.zip，完整解压后进入 CornerBreak 文件夹，双击 CornerBreak.exe。

需要 Windows 和 .NET Framework 4.7.2 或兼容更新版本。请保留 CornerBreak.exe.config。

CornerBreak-v0.2.0-windows.zip.sha256 用于核对 ZIP 的 SHA256。

## 保留个人设置

设置位于程序同目录的 Data/settings.json。搬迁或升级时保留 Data 文件夹。

旧设置缺少常驻选项时，默认启用常驻小挂件；原有提醒开关、角色、暂停和跳过状态保留。程序不会自动设置开机启动。
