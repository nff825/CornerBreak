# CornerBreak macOS 0.2.0-beta.1 · 测试清单

本版由 Windows 交叉构建，尚未经过 Mac 实机验证，未使用 Developer ID 签名或通过 Apple 公证。目标系统为 macOS 14 或更新版本。测试者不需要安装 .NET 或开发工具。

请按设备选择 ARM64（M 系列芯片）或 x64（Intel）压缩包，并确认下载来源与随附 SHA256 一致。

## 先做三分钟快速检查

- [ ] 解压后双击 CornerBreak.app，是否能启动？如有系统提示，请截图，不必反复尝试。
- [ ] 屏幕上是否出现小挂件？文字和所选伙伴是否清晰完整？
- [ ] 点击小挂件，能否打开详情？
- [ ] 使用菜单栏图标或挂件右键菜单的“查看状态”，能否打开状态窗口？这一步无需等待休息时段。
- [ ] 打开“提醒设置”，能否保存修改并取消未保存的修改？
- [ ] 通过菜单中的“退出 CornerBreak”，是否能退出，挂件和菜单栏入口是否一起消失？

若启动阶段提示开发者无法验证，请先确认来源和 SHA256，再参考 [Apple 官方说明](https://support.apple.com/en-us/102445)。若提示已损坏、会损坏电脑或直接闪退，请先反馈截图和设备信息；无需关闭系统安全保护或运行处理隔离属性的命令。

## 常驻挂件与交互

- [ ] 平时等待下一次休息时，小挂件保持可见，倒计时持续变化。
- [ ] 切到浏览器、文档等普通应用后，小挂件是否仍可见？
- [ ] 前台正在输入时，挂件刷新是否抢走键盘焦点？
- [ ] 点击角色、文字和空白区域，是否均能打开详情？
- [ ] 拖动后在挂件之外松开鼠标，挂件是否停止移动，且不会误打开详情？
- [ ] 拖到屏幕边缘，是否仍能看见并移回？
- [ ] 右击挂件，菜单中的查看状态、设置、暂停、伙伴选择和退出是否可用？
- [ ] 关闭详情窗口后，是否回到挂件，并保留原倒计时？
- [ ] 关闭“常驻小挂件”，等待期间是否隐藏？重新开启后是否出现？

## 角色与设置保存

- [ ] 分别切换猫猫探头、蓝色大肥鱼、二次元伙伴，显示是否正确？
- [ ] 选择“不显示角色”后，文字和倒计时是否仍正常？
- [ ] 三项提醒开关是否分别生效？
- [ ] 关闭自动放大后，提醒卡片是否保持固定尺寸？
- [ ] 修改后点“取消”，原设置是否保持？
- [ ] 保存设置、拖动挂件，然后退出并重新打开：模式、角色、开关与位置是否保留？

## 暂停、跳过与提醒时刻

- [ ] 暂停 30 分钟后，挂件是否显示已暂停和恢复倒计时？可以立即手动恢复，不必等满 30 分钟。
- [ ] 选择“暂停，直到手动恢复”后，挂件是否显示等待手动恢复？
- [ ] 点击恢复提醒后，是否按当前真实时段恢复，而不是重新从十分钟开始？
- [ ] 在每小时 50 分时，是否从小挂件展开提醒？
- [ ] 例如 14:55 启动时，是否显示接近 05:00，而不是固定 10:00？
- [ ] 越接近整点，卡片、文字和伙伴是否逐渐变大？是否保持在屏幕范围内？
- [ ] 鼠标停留、拖动、使用菜单或设置时，自动变化是否暂缓？
- [ ] “收起详情”只回到小挂件；本轮内是否保持收起，继续显示休息剩余时间，而没有显示“本轮已跳过”？
- [ ] “本轮不再提示”是否显示本轮已跳过？退出并重开后本轮是否仍然跳过？
- [ ] 到整点后，是否回到等待状态？下一轮是否能正常提醒？

## Mac 特有的重点项目

以下行为尚未验证，请记录实际结果，不必为了覆盖所有情况调整自己的日常工作环境。

- [ ] 切换 Spaces、使用 Mission Control 或 Stage Manager 时，挂件出现在哪个桌面？
- [ ] 其他应用全屏时，挂件是否显示？退出全屏后是否能找回？
- [ ] 外接显示器、不同缩放、拔除外接屏后，挂件是否留在可见范围？
- [ ] 睡眠后唤醒，倒计时是否立即按当前时间更新？跨过休息时段后是否显示正确状态？
- [ ] 菜单栏入口是否可找到，是否存在挂件消失后无法打开或退出的情况？

本版不承诺在所有全屏、Spaces 或系统界面之上始终显示。
